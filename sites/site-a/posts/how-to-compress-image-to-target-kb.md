# 在线把图片压缩到指定大小（200KB/500KB）— 目标体积压缩教程

报名系统、政务平台、招聘网站常写：**「单张图片不超过 200KB」**。只凭感觉拖「质量」滑块，往往要么画质浪费、要么还是超标。本文介绍 [wordok.top 图片处理百宝箱](https://wordok.top/tools/) 新增的 **按目标体积自动调质量** 用法。

## 一、适用场景

- 证件照、简历照上传有 **KB 上限**
- 邮件附件需要控制在 **500KB 以内**
- 论坛/表单限制 **单图体积**
- 希望在压缩同时 **去掉 EXIF**（拍摄时间、GPS 等）

## 二、操作步骤（约 1 分钟）

1. 打开 [https://wordok.top/tools/](https://wordok.top/tools/) ，切换到 **「图片压缩」** 标签。
2. 上传或拖拽图片（支持 PNG、JPG、WEBP、BMP、GIF）。
3. 在 **「目标体积 (KB)」** 输入框填写目标，例如 `200`。
4. 建议勾选 **「导出时去除 EXIF 元数据」**（默认已勾选）。
5. 输出格式选 **JPG** 或 **WEBP**（照片类压缩效果更好）。
6. 点击 **「按目标体积自动调质量」**，等待提示；查看压缩前后大小对比。
7. 满意后点击 **「下载压缩图片」**。

> 说明：所有处理在浏览器本地完成，**图片不会上传到服务器**。

## 三、压不到目标时怎么处理？

| 情况 | 建议 |
|------|------|
| 原图分辨率很大（如 4000×3000） | 先到 **「尺寸调整」** 把宽边缩到 1200～1920px，再压缩 |
| 格式为 PNG 照片 | 压缩页选择输出 **JPG** 或 **WEBP** |
| 已是最低质量仍超标 | 继续缩小尺寸，或裁剪无关区域（**图片裁切**） |
| 需要透明背景 | 保留 PNG，接受体积较大，或改用 WEBP |

可配合阅读：[教你如何把图片压缩到200KB以下](how-to-compress-image-to-200kb.md)、[PNG与JPG格式选择指南](png-vs-jpg-image-format-guide.md)。

## 四、EXIF 与隐私

手机照片常含拍摄时间、机型、甚至 GPS。上传到公开平台前，建议：

- 在压缩页勾选去除 EXIF 后导出；或
- 使用格式转换/压缩重新编码（Canvas 导出通常不保留原 EXIF）。

更多背景见：[如何给图片添加水印](how-to-add-watermark-to-image.md)（版权与发布场景）。

## 五、与手动滑块的区别

- **质量滑块**：你指定画质，体积是结果。
- **目标体积**：你指定 KB 上限，工具自动找接近的质量。

两者可组合：先用目标体积接近 200KB，再微调滑块做最后优化。

## 六、常见问题

**Q：会自动上传到云端吗？**  
A：不会，与百宝箱其他功能一样，纯本地处理。

**Q：批量多张怎么办？**  
A：当前页面为单张处理；多张请逐张操作，或使用命令行工具 `npm run remove-watermark` 等本地脚本处理特殊需求。
